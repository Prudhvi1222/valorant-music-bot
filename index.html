A lightweight music-request experience designed for VALORANT players. Players can request a song, the system manages the queue, retrieves song metadata, and presents a clear Now Playing notification.

How the prototype works

The intended flow is deliberately simple and focused on entertainment rather than competitive gameplay.

01

Request

Player enters a music request.

02

Identify

The system associates the request with the player and resolves the song.

03

Queue

The music engine adds the request to the playback queue.

04

Play

The system presents the Now Playing information and plays the queued track.

Designed with Riot's developer policies in mind

This project is intended as an optional, non-competitive entertainment experience. It does not provide gameplay advantages, analyze gameplay, modify game files, read game memory, use code injection, scrape undocumented endpoints, or attempt to bypass Vanguard protections. The project intends to use Riot's officially supported developer tools and APIs wherever applicable. Any functionality involving VALORANT player-facing systems will be implemented only where Riot provides or permits an official integration.
